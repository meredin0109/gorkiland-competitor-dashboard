# Конкурентный дашборд рынка аттракционов РФ

Интерактивный обзор производственных линеек, сильных и слабых сторон и конкурентных позиций 12 производителей и поставщиков, включая ГоркиLAND, фабрику аттракционов «Сказка» и «Бизнес Парк».

## Публикация

Статический сайт. Главная страница — `index.html`; данные и интерактивные фильтры находятся в `app.js`; стили — `styles.css`. Внешние библиотеки JavaScript не используются. Шрифт загружается из Google Fonts с системным резервным вариантом.

## Методика

Матрица отражает качественную оценку открытых каталогов и материалов производителей, собранных на 16 ноября 2026 года. Профиль «Бизнес Парка» добавлен 27 ноября 2026 года по каталогу поставщика. Оценки не являются рыночными долями, независимым аудитом качества, надёжности или цен. Сведения требуют проверки по конкретным моделям, документам и коммерческим предложениям.

## Основной источник

«Конкурентный анализ ГоркиLAND РФ» — подготовленный аналитический документ. В карточках производителей приведены ссылки на сайты компаний и отраслевые публикации, использованные в исследовании.
